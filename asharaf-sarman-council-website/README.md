# Asharaf Sarman Council Website

This is a Vite React website prepared for GitHub and Vercel deployment.

## Run locally

```bash
npm install
npm run dev
```

## Deploy on Vercel

1. Create a GitHub repository.
2. Upload all files from this folder.
3. Go to Vercel and choose **Add New Project**.
4. Import the GitHub repository.
5. Keep default Vite settings.
6. Click **Deploy**.
